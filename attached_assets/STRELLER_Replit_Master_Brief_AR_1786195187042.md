لا يجوز نشر أي معلومة غير مؤكدة، مثل:

- “أكبر معرض في أوروبا”.

- تسجيلات أو عناوين أو أرقام غير مقدمة رسميًا.
- أرقام زوار أو عوائد أو نسب نجاح تقديرية على أنها حقائق.

استخدم بدلًا من ذلك:

- “in development”
- “planned”
- “proposed host format”
- “seeking our first European host-city partner”
- “working with specialist partners at each stage”

9. CONTACT FORM BACK END
==================================================

Create POST /api/contact.

Use Zod validation. Fields:
- name: 2–100 chars
- organisation: 2–150 chars
- email: valid email
- location: optional, max 120 chars
- inquiryType: enum
- message: 20–3000 chars
- consent: true
- website: hidden honeypot; reject when filled

Add a basic IP-based rate limit suitable for a single Replit instance. Store valid submissions in SQLite with createdAt, locale, userAgent and status. Never store raw IP addresses; hash or omit them.

If RESEND_API_KEY and CONTACT_TO_EMAIL exist, send a notification. If they do not exist, saving to SQLite is enough and the UI must still return a real successful result.

Add .env.example:
SITE_URL=
CONTACT_TO_EMAIL=
RESEND_API_KEY=

Do not hard-code a public email address until it is confirmed.

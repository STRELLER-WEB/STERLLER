────────────────────────
CREATIVE DECISION SYSTEM
────────────────────────

Before applying any animation, analyze:

1. What is the purpose of this section?
2. What should the user's attention focus on first?
3. Is animation actually necessary?
4. What motion style best supports the content?
5. How does this animation connect visually with the previous and next sections?
6. Will this animation improve hierarchy, storytelling, feedback, depth, or usability?
7. Will it remain elegant and smooth on desktop and mobile?
8. Is there a simpler effect that achieves the same result better?

Choose effects based on context.

You are encouraged to combine multiple techniques when they naturally complement each other, but never stack effects purely for decoration.

────────────────────────
VISUAL COHERENCE
────────────────────────

The entire landing page must feel like ONE unified motion system.

Maintain consistency in:

• easing curves
• animation timing
• transition speed
• motion direction
• depth
• shadows
• blur
• glow intensity
• border treatments
• gradient behavior
• perspective
• hover behavior
• spacing rhythm
• visual hierarchy

Animations between sections should feel connected rather than isolated.

Establish a recognizable motion language for the entire website.

For example:
entrance animations should share a similar motion personality,
interactive elements should share similar feedback behavior,
and major sections should share a consistent cinematic language.

────────────────────────
SCROLL EXPERIENCE
────────────────────────

Design scrolling as part of the experience.

Use smooth scrolling where appropriate.

Create a natural visual rhythm:

calm → reveal → interaction → emphasis → breathing space → next moment.

Do not animate everything simultaneously.

Use stagger and sequencing to guide attention.

Scroll-triggered animations should activate naturally as content enters the viewport.

Avoid excessive scroll hijacking.

If pinned or sticky storytelling is used, it must serve a clear narrative purpose.

Give special attention to the Hero.

────────────────────────
CARDS & CONTENT
────────────────────────

Avoid applying identical animation to every card.

Create subtle variation based on content importance.

Potential treatments include:

Keep card interactions elegant and predictable.

────────────────────────
TYPOGRAPHY
────────────────────────

Use text animation strategically.

Headlines can use stronger typography animation.

Body text should remain calm and readable.

Avoid excessive character-by-character animation.

Use text motion primarily to reinforce hierarchy and storytelling.

────────────────────────
DEPTH & LIGHTING
────────────────────────

Use shadows, blur, gradients, glow, glass, perspective, and lighting as a coordinated depth system.

Do not randomly place glowing objects.

Light sources should feel visually intentional.

Maintain consistent lighting direction and glow behavior throughout the page.

────────────────────────
PERFORMANCE
────────────────────────

The page must remain fast and smooth.

Target 60 FPS.

Prefer GPU-friendly transforms:
transform,
translate,
scale,
rotate,
opacity.

Avoid unnecessary layout-triggering animations.

Use expensive effects such as WebGL, shaders, particles, blur, 3D, or distortion only when they create meaningful visual value.

Lazy-load heavy visual assets when appropriate.

Optimize especially for mobile devices.

────────────────────────
RESPONSIVENESS
────────────────────────

Do not simply shrink desktop animations for mobile.

Adapt the motion system specifically for:

Desktop
Tablet
Mobile

Reduce complexity and movement on smaller or weaker devices where appropriate.

Disable cursor-specific interactions on touch devices.

Simplify heavy parallax, WebGL, particles, or 3D when necessary.

────────────────────────
ACCESSIBILITY
────────────────────────

Respect:

prefers-reduced-motion

Provide reduced-motion alternatives for users who disable animation.

Never allow animation to prevent users from reading or interacting with content.

Never sacrifice usability for visual effects.

────────────────────────
AVOID
────────────────────────

Avoid:

random animations,
animation on every element,
excessive bouncing,
excessive glowing,
too many gradients,
too many particles,
constant movement everywhere,
unnecessary 3D,
overly long transitions,
repetitive reveal animations,
aggressive scroll hijacking,
animations that delay interaction,
visual clutter,
conflicting motion directions,
effects added only because they look impressive.

Never make the website feel like a motion-effects demo.
